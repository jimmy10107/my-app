# 《往返 TO AND FROM》史料主張表｜來源與佐證台帳

依《往返》策展文史補強診斷的建議，這是「優先清單」第一項：逐句列出要上牆的事實、來源、權利與查證狀態。**只有 A／B 級且無爭議的敘述可以直接送印；C／D 級或有版本分歧的內容，展場文字一律加註「相傳」「一說」或並陳多版本，不使用肯定句。**

## 佐證等級定義

| 等級 | 定義 |
| --- | --- |
| A｜官方／一級史料 | 政府機關、文化資產主管機關、公營事業之官方登錄或正式公告 |
| B｜學術／出版 | 期刊論文、專書、政府委託之調查研究報告 |
| C｜口述／媒體 | 新聞報導、地方文史工作者整理、口述訪談 |
| D｜待查 | 目前查無可靠來源，或僅見於未註明出處的網頁／部落格 |

## 送印紅線（取得足夠證據前不應送印）

以下項目維持原診斷文件的紅線判斷，本輪研究未發現足以解除紅線的新證據：

1. 日南（九里）占大甲稻米產量的精確比例 — **確認為統計資料結構性缺口，非待查而是「查無此資料公開發布」**。
2. 日南營區的軍種、編制、年代與移交歷程 — **本輪搜尋完全查無公開紀錄**。
3. 藺編起源的人名、年代與「第一位」等排他性主張 — **本輪研究發現至少三個彼此不一致的版本**，其中一版本牽涉日南社本身，需另外查證後才能決定展場措辭，但無論如何都不應寫成單一肯定句。
4. 台鐵／JR九州姊妹站協定中標誌與照片的使用授權範圍 — **未能確認協定條款細節**，需另行取得書面確認。
5. 未取得本人核稿的口述引句、肖像與家族故事。
6. 未取得授權的老照片、臺鐵／JR識別、站牌圖像與出版物掃描。

## 已解除或可修正的項目

1. **日南車站啟用日期**：兩個官方一級來源（國家文化資產網、臺中市文化資產處）一致採 **1922年10月30日**，可作為展板正式日期，並加註10/11一說出處不明。
2. **雙日南姊妹站關係**：2023年締結已有多方官方與媒體來源佐證，可正式陳述交流關係，唯標誌／照片使用仍需另外取得授權。
3. **幼獅工業區與軍方用地的關聯猜測**：已排除，工業區為青輔會／經濟部工業局於1975年開闢之產業園區。

## 待辦研究（建議走線下管道，非網路搜尋能解決）

- 調閱《臺中縣縣定古蹟「縱貫鐵路（海線）追分、日南車站」調查研究》全文（國家圖書館台灣記憶系統典藏），可能同時解決車站啟用日期與建築細節考證。
- 向臺中市大甲區公所／大甲區農會查詢日南地區稻作面積與產量的內部資料（非公開統計，需正式發函）。
- 向國防部軍備局／陸軍司令部或大甲區公所查詢「日南營區」是否確有其事。
- 直接瀏覽台鐵全球資訊網「國際鐵道觀光交流」姊妹站頁面（第28號）與JR九州官方新聞稿PDF全文，確認標誌／照片使用授權範圍。
- 向苗栗縣立圖書館《苗栗文獻》編輯部查詢藺編起源是否有更嚴謹的學術考證，特別是「日南社蚋西烏毛」版本的可信度。
